# --- orchestration (airflow/) ---
# apache-airflow is deliberately NOT listed here -- see
# airflow/requirements-airflow.txt and airflow/README.md's "Why Airflow
# gets its own virtual environment" section. Short version: every
# Airflow 2.x release hard-pins sqlalchemy<2.0, which directly conflicts
# with the sqlalchemy==2.* this project's dbt/dlt stack needs -- not a
# Windows quirk, a real, unresolvable pin conflict on any OS. Airflow is
# installed into its own venv instead, and its DAG only ever shells out
# to this venv's `dbt` by absolute path, so the two never need to share
# a dependency tree.
